2. Add it in Claude

  1. In Claude, open Settings › Connectors and click Add custom connector.
  2. Paste the MCP server URL above into the Remote MCP server URL field.
  3. Open Advanced settings and paste your Client ID and Client Secret.
  4. Click Add, then Connect. Log in to your site and approve access when asked.
  5. Test it — ask Claude: show me my latest blog posts.
